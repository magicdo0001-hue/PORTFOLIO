# 统一字体规范与验收

更新日期：2026-10-08。此前的 `font-audit-2026-10-08.md` 是统一前的检查记录。

## 当前字体分工

| 角色 | 字体栈 | 用途 |
| --- | --- | --- |
| 正文 / UI | MiSans, sans-serif | 中文、说明文字、导航、按钮、状态提示、图注、设备界面 |
| 展示标题 | Manrope, MiSans, sans-serif | 英文项目名称和展示标题；中文字符由 MiSans 绘制 |
| 编号 / 数据 | Azeret Mono, MiSans, monospace | 档案编号、章节编号、参数、进度、设备读数；混排中文由 MiSans 绘制 |

唯一共享定义为 `shared/typography.css`，由主站 layout、RhineLab 样式和 SANGRE 样式接入。字体沿用仓库已有资产，没有新增字体家族、二进制源文件或依赖。构建器按各入口的部署路径生成字体 URL，因此本地主站和独立构建都能解析资源。

- MiSans：300、400、600、700。正文使用 400，主要中文标题使用 600；原有首页品牌字和设备内的粗体强调保留必要的粗字重。
- Manrope：共享配置使用 400、500；英文标题默认以 400/500 呈现。
- Azeret Mono：300、400，用于标签和数据。CSS 名称统一为 `Azeret Mono`。
- 三套字体均为本地 `@font-face`，使用 `font-display: swap`。不依赖访客系统安装 Aptos、Helvetica Neue、Georgia 或 Cascadia Mono。
- `font-synthesis: none` 避免浏览器制造不存在的粗体/斜体。中文标题的 600 请求可匹配 MiSans 600，其中拉丁字符会匹配已有 Manrope 字重。
- 首页经过校准的品牌标识及 Canvas 实体档案标签继续使用 MiSans；页面编号改用 Azeret Mono，并在进入场景前等待其加载。
- 图片、视频、PDF 内的文字不随网页字体更换。未挂载的旧 orbit、第三方 vendor 的休眠规则、辅助检查页和独立 Quiet Focus 模板不属于此次主站样式替换范围。

## 页面覆盖

首页外层工具条、档案界面、打开项目的准备提示、作品目录、五个项目的中英文页面、BAMBINO 工作台与阅读模式、项目城市首屏、SANGRE 展示与静态降级版、案例正文和设备屏幕。

主站正文和图注统一使用 MiSans；删除主站原有衬线强调分支，以字号、字重、行距区分层级。英文展示标题使用 Manrope，数据才使用等宽字体，避免长图注和说明文字都呈现为参数面板。

## Design Taste Frontend 排版验收

设计判断：面向作品集读者的设计师个人网站，保留档案界面和产品展示的技术感，以现有原生 CSS 做字体与阅读节奏的局部统一。

模式为 **Redesign — Preserve**。现有页面的设计差异、动效和密度按约 `8 / 7 / 4` 理解，本次不增加动效或改换视觉方向。配色、模型、素材、文案、路由和品牌标识保持既有设计。Skill 中面向全新页面的结构改造建议不扩展本次字体任务范围。

| 验收项目 | 结果与处理 |
| --- | --- |
| 主次层级 | 中文/正文、英文展示和数据三类字体可区分；首页与新版详情页的字体语汇已贯通。 |
| 标题疏密 | 目录强调标题原有过紧的负字距和 0.9 行高已调整；去掉衬线斜体，增加均衡换行，英文桌面标题单独限制字号。 |
| 手机断行 | 360px、390px 检查了长英文标题、中文案例、BAMBINO 和目录强调语，没有发现新增的横向溢出或被裁切的标题。 |
| 平板控件 | 768px 的 UniLife / ARTI64 英文底部控件曾越过右边界；已增加 761–1100px 分行规则，修订后复测通过。 |
| 导航与按钮 | 桌面导航保持单行，关键按钮没有因换字体变为挤压换行；交互状态可识别。 |
| 正文与图注 | 正文采用 MiSans，图注恢复比例字体；保留原有内容宽度与阅读层级。 |
| 数据 | 档案滚动数字为 Azeret Mono；SANGRE 屏幕数字改用同一等宽字体并保留单位的正文字体。 |
| 视觉保留 | 首页品牌构图、档案模型、城市模型、SANGRE 配色与镜头保持原样。 |

## 已知限制

- 未在 Safari、Firefox、真实 iOS/Android 设备上验证，也未做弱网性能基准。
- MiSans 沿用已有完整字库，单个字重约 4.8–5.1 MB；各独立构建会生成自己的字体 URL，跨页面首次访问可能重复传输。此次完成视觉统一，未做字库子集化或跨入口字体缓存优化。
- 构建仍提示既有 JavaScript 大包警告；没有将本次字体调整扩大为模型或运行时拆包改造。
